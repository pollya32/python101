# 엑셀 붙여넣기 분석 시스템

엑셀에서 표를 복사해 붙여넣기만 하면 자동으로 분석합니다. 왼쪽 사이드바에서 **분석 모드**를 고르세요.

**Windows: `실행.bat` 더블클릭** (Python 3.9+ 설치 필요 — 설치 시 "Add python.exe to PATH" 체크)
- 첫 실행 때 이 폴더에 전용 환경(`.venv`)을 만들고 패키지를 설치합니다 (몇 분). 이후에는 바로 실행됩니다.
- `requirements.txt` 가 바뀌면 다음 실행 때 자동으로 다시 설치합니다.
- 회사망에서 설치가 막히면 `실행.bat` 위쪽에 `set HTTPS_PROXY=http://프록시주소:포트` 를 추가하세요.

직접 실행:
```bash
pip install -r requirements.txt
streamlit run 상관분석.py
```

| 🧪 FDC LOT/Wafer 분석 | 세로형(LOT·Wafer·Step·파라미터·값) 또는 가로형 | 세로형 → Wafer(또는 LOT)별 자동 변환(평균·표준편차·범위 등, `Step:파라미터` 열), 결과표(수율) LOT·Wafer 기준 병합, Wafer/LOT 평균 분석 단위 선택, LOT 간·LOT 내 변동 비율, 슬롯 번호별 프로파일, Good vs Bad LOT 원인 파라미터 순위(효과크기 d), 설비별 상관 히트맵, I-관리도(UCL/LCL, USL/LSL, 연속 7점 드리프트, Cpk) |

| 📅 월별 비용 추이 | 부품 사용 비용 | 월/분기/주 단위 합계·평균·건수, 설비·부품별 추이, 전기 대비 증감, 파레토(80% 차지 항목) |
| ⚖️ 그룹 평균 비교 | 수리비 평균 비교 | 그룹별 건수·평균·중앙값·95% 신뢰구간, ANOVA·Kruskal-Wallis, 쌍별 비교, 교차 평균표(설비 × 부품) |

## 공통
- 📋 붙여넣기(탭/쉼표 자동 감지) 또는 xlsx/csv 업로드, 샘플 데이터 3종 내장
- 🔢 `1,200,000` · `45%` · `₩3,000` · `(500)` · `#N/A` 자동 정제
- 📆 `2024-01-05` · `2024.01` · `2024/1/5 13:20` · `2024년 1월` 날짜 자동 인식
- 🧭 수치형 / 범주형 / 날짜형 / 제외(LOT ID 등) 자동 분류, 행↔열 전치
- 🔽 사이드바 필터 (예: 구분 = 수리만, 기간 범위)
- 📥 결과 엑셀 다운로드

## FDC 세로형 사용법
열 역할(LOT·Wafer·Step·파라미터·값)은 이름(한글·영문: LotID, Slot, Oper, SVID, Value …)으로 먼저 찾고, 없으면 값 모양과 구조로 추정합니다. 결과표의 LOT·Wafer 열은 FDC 쪽 값과 겹치는 열로 찾고, Wafer 표기(W07·07·7)는 끝 번호로 맞춥니다.

1. 📋 붙여넣기 탭: `LOT | Wafer | Step | (설비 | 진행일시 …) | 파라미터 | 값` 원본
2. 🎯 결과 데이터 탭: `LOT | Wafer | 수율 | CD …` (선택, `W07`·`07`·`7` 표기 차이는 자동으로 맞춤)
3. FDC 모드에서 열 매핑·요약 방법(평균/표준편차 등)·Step 선택 → Good/Bad 원인 파라미터 확인
4. **📄 자동 리포트 탭**: 핵심 요약(의심 파라미터, LOT/Wafer 원인 구분, 슬롯 효과, 설비 편차, 관리도 이상 LOT)과 상위 N개 파라미터별 그래프 → HTML(오프라인, Ctrl+P로 PDF) · 엑셀 다운로드
5. **⚖️ 챔버 매칭 탭**: 챔버(설비, 설비+챔버 조합)별 파라미터 평균 오프셋(σ)·산포비를 전체 챔버 중앙값 또는 골든 챔버와 비교 → 매칭률, 히트맵, 불일치 목록(수율 영향 파라미터 우선), 챔버별 결과값 분포. `ETCH:설비`로 매칭하면 ETCH Step 파라미터만 비교. 자동 리포트에도 포함
6. 관리도는 기본적으로 LOT 평균 점으로 그림 (Wafer 점은 같은 LOT끼리 비슷해 관리한계가 좁게 잡혀 오경보가 많음)

## 부품 비용 분석 사용법
1. 📋 붙여넣기 탭: `사용일 | 설비 | 부품코드 | 부품명 | 구분 | 수량 | 단가 | 금액` (일부 열이 없어도 됨: 금액 또는 수량+단가만 있으면 계산)
2. 🏭 생산량 / FDC 탭 (선택): `월 | 설비 | 생산량` → Wafer당 부품비, FDC 원본(시각·설비·파라미터·값) → 교체 전후 FDC 변화
3. ⚙️ 분석 설정: 비교 기간 A/B, 교체로 볼 구분, 조기 교체 기준(기본: 부품 기준 주기의 50%), 연간 예산, FDC 비교 구간
4. 📄 자동 리포트 → HTML(인쇄 → PDF) · 엑셀
