# 엑셀 붙여넣기 상관분석 시스템

엑셀에서 표를 복사해 붙여넣기만 하면 **열(항목) 간 상관관계**를 자동으로 분석합니다.

```bash
pip install -r requirements.txt
streamlit run 상관분석.py
```

## 기능
- 📋 붙여넣기(탭/쉼표 자동 감지) 또는 xlsx/csv 업로드
- 🔢 `1,200,000` · `45%` · `₩3,000` · `(500)` · `#N/A` 같은 엑셀 표기 자동 정제
- 🧭 수치형 / 범주형 / 제외(ID·날짜) 항목 자동 분류, 행↔열 전치 지원
- 🟥 상관 히트맵 (피어슨 · 스피어만 · 켄달)
- 🏆 항목 쌍 상관 순위 + p-value + 다중검정 보정(BH-FDR) + 한글 해석
- 🎯 타깃 항목 기준 영향 항목 막대그래프
- 📈 산점도 + 추세선 + 범주별 색상
- 🏷️ 범주형 ↔ 수치형 연관도(η) + 박스플롯
- 📥 결과 엑셀 다운로드
