탐색기 보기 설정 일괄 변경 - 사용법
==================================================

D 드라이브와 모든 하위 폴더의 탐색기 보기를 한 번에 아래처럼 바꿉니다.
  - 보기: 자세히
  - 정렬 기준: 수정한 날짜 (최신 순)
  - 분류 방법: 유형


1. 준비
--------------------------------------------------
  1) 받은 zip 파일을 오른쪽 클릭 → "모두 압축 풀기"
  2) 압축을 푼 폴더 안의 파일들은 같은 폴더에 함께 두세요.
     (bat 파일은 같은 이름의 ps1 파일을 실행합니다)
  3) 파이썬은 필요 없습니다. 윈도우 기본 PowerShell로 실행됩니다.


2. 건너뛸 폴더 지정 (선택)
--------------------------------------------------
  "건너뛸_폴더.txt"를 메모장으로 열고 한 줄에 하나씩 경로를 적은 뒤 저장합니다.

    D:\사진          → 이 폴더만 건너뜀 (하위 폴더에는 적용)
    D:\음악\*        → 이 폴더와 모든 하위 폴더를 건너뜀

  - '#'으로 시작하는 줄은 무시합니다.
  - 경로는 탐색기 주소창에서 복사해 붙여 넣으면 편합니다.
  - 건너뛸 폴더가 없으면 그대로 두면 됩니다.


3. 보기 설정 바꾸기
--------------------------------------------------
  1) "탐색기_보기설정_일괄변경.bat" 더블클릭
  2) 대상 폴더 개수가 나오면 "y" 입력 후 Enter
  3) 탐색기 창이 열리고 폴더를 하나씩 이동합니다.
     끝날 때까지 이 탐색기 창을 닫거나 조작하지 마세요.
     (폴더당 약 0.1~0.5초, 폴더가 많으면 몇 분 걸립니다)
  4) "완료" 메시지가 나오면 아무 키나 눌러 창을 닫습니다.

  - 실행 후 개별 폴더에서 따로 바꾼 보기 설정은 그대로 유지됩니다.
  - 다시 실행하면 D 드라이브 폴더가 다시 덮어써지니,
    지키고 싶은 폴더는 "건너뛸_폴더.txt"에 적어 두세요.
  - 실행 후 새로 만든 폴더에는 적용되지 않습니다. 필요하면 다시 실행하세요.


4. 원래대로 되돌리기
--------------------------------------------------
  1) "탐색기_보기설정_되돌리기.bat" 더블클릭
  2) "y" 입력 후 Enter

  주의: D 드라이브만이 아니라 PC 전체의 폴더 보기 설정이
        윈도우 기본값으로 초기화됩니다.
        열린 탐색기 창은 모두 닫히고 작업 표시줄이 잠깐 사라졌다 돌아옵니다.

  초기화 전 설정은 "백업_날짜_시간" 폴더에 .reg 파일로 저장됩니다.
  되돌리기를 취소하고 싶으면 그 .reg 파일들을 더블클릭해 복원한 뒤
  로그아웃했다 다시 로그인하세요.


5. 문제 해결
--------------------------------------------------
  - "Windows의 PC 보호" 창이 뜨면: "추가 정보" → "실행"
  - 실패한 폴더가 있으면: 권한이 없는 시스템 폴더일 수 있습니다.
    결과 화면에 최대 20개까지 경로가 표시됩니다.


6. 고급 사용 (명령줄)
--------------------------------------------------
  PowerShell에서 이 폴더로 이동한 뒤:

    powershell -ExecutionPolicy Bypass -File .\탐색기_보기설정_일괄변경.ps1 -DryRun     대상 폴더 개수만 확인
    powershell -ExecutionPolicy Bypass -File .\탐색기_보기설정_일괄변경.ps1 E:\사진     다른 폴더에 적용
    powershell -ExecutionPolicy Bypass -File .\탐색기_보기설정_일괄변경.ps1 -Yes        확인 없이 실행

  파이썬 버전 (pip install pywin32 필요):

    python 탐색기_보기설정_일괄변경.py --dry-run
    python 탐색기_보기설정_일괄변경.py E:\사진
    python 탐색기_보기설정_되돌리기.py
