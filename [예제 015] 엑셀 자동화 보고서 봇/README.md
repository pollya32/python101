# [예제 015] 엑셀 자동화 보고서 봇

여러 지점(또는 여러 담당자)이 각자 작성한 엑셀 파일들을 한 번에 취합해서,
지점별 · 월별 · 카테고리별 요약이 담긴 서식 적용 보고서를 자동으로 만들어주는 스크립트입니다.

매번 반복되는 "여러 파일 받아서 하나로 합치고, 피벗 만들고, 서식 입히기" 작업을 자동화합니다.

## 설치
```bash
pip install -r requirements.txt
```

## 사용법

1. (선택) 샘플 데이터로 바로 테스트해보고 싶다면:
   ```bash
   python generate_sample_reports.py
   ```
   `input/` 폴더에 지점별 샘플 xlsx 파일(지점당 1~3월 시트)이 생성됩니다.

2. 실제로 사용할 때는 `input/` 폴더에 아래 컬럼을 포함한 xlsx 파일들을 넣어주세요.
   파일 개수, 시트 개수는 몇 개든 상관없습니다.

   | 날짜 | 지점 | 담당자 | 카테고리 | 매출액 | 비용 |
   |---|---|---|---|---|---|

3. 보고서 생성:
   ```bash
   python excel_report_bot.py
   ```
   `output/보고서_YYYYMMDD_HHMMSS.xlsx` 파일이 생성됩니다. 실행할 때마다 새 파일이
   만들어져서 이전 보고서를 덮어쓰지 않습니다.

   입력/출력 폴더를 바꾸고 싶다면:
   ```bash
   python excel_report_bot.py --input 내데이터폴더 --output 결과폴더
   ```

## 결과 보고서 구성

- **원본취합**: 모든 파일 · 시트의 데이터를 하나로 합친 원본
- **지점별요약**: 지점별 매출 / 비용 / 순이익 합계
- **월별요약**: 월 × 지점별 매출 / 비용 / 순이익 합계
- **카테고리별요약**: 카테고리별 매출 / 비용 / 순이익 합계

## 활용 팁

- 팀원들이 매주 · 매월 같은 양식으로 엑셀을 채워서 공유 폴더(`input/`)에 넣기만 하면,
  이 스크립트를 실행할 때마다 최신 취합 보고서를 바로 뽑을 수 있습니다.
- `REQUIRED_COLUMNS`와 `summarize()` 함수만 각자의 데이터에 맞게 수정하면
  다른 종류의 반복 보고서에도 그대로 재사용할 수 있습니다.
